This build has no OAuth client id yet, so Sign in with GitHub is off. Register an OAuth App (Settings → Developer settings), tick Enable Device Flow, and paste the client id into auth.js. Until then, use a token under Advanced below.

Advanced — use a personal access token instead

Only for when you'd rather not sign in. Signing in with GitHub above replaces anything set here.

  1. Open github.com/settings/personal-access-tokens/new
  2. Give it a name and an expiry.
  3. Repository access → Only select repositories → pick your notes repo.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate, copy it, and paste it above. It's shown once.

A classic token with the repo scope works too.
